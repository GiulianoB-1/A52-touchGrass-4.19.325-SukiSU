Phase 218 is observation-only and records metadata around the first failing KeyMint/QSEE boundary:
- opens and returns for qseecom, ion, storage and secure-app firmware paths
- QSEECom ioctl numbers, exact returns, handle type, app id and listener id
- listener registration metadata: listener id, file descriptor and size

No command buffers, response buffers, key material, authentication tokens, Binder payloads or process memory are recorded. Existing R48 three-copy transport, Reed-Solomon parity, CRC32C, boot-image invariants and decoder checks remain mandatory.
