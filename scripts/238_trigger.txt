Phase 238 hardware test - broad GPU supplier-chain recorder

1. Build the Phase 238 workflow artifact from branch:
   agent/a52-phase238-broad-gpu-supplier-recorder-v1

2. Verify SHA256SUMS and package audit before flashing.

3. Flash only:
   package/boot.img -> BOOT partition

4. Boot the phone normally.

5. Let the failing boot run for at least 155 seconds so the 145-second Phase 238 replay executes. If the same watchdog behavior remains, letting the device continue until the natural watchdog reboot is preferred because it also preserves the later SurfaceFlinger/KGSL attempts.

6. Use the existing OrangeFox R48 collector v3.2 to capture the raw ramoops exactly as with Phase 237. Do not switch decoders or collectors.
